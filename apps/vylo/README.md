# Vylo — карта путешествий

**Исследуй. Сохраняй. Встречайся. Делись.** Мобильное веб-приложение (PWA) для путешественников: 3D-глобус с
местами, визы для граждан РФ, встречи с путешественниками рядом, планировщик поездок и паспорт, который хочется
заполнять.

Next.js 16 · React 19 · Tailwind v4 · Framer Motion · MapLibre GL (глобус) · Zustand. Полностью статический билд:
данные встроены, состояние пользователя хранится в `localStorage`, сервер не нужен.

## Запуск

```bash
pnpm install
pnpm --filter @vylo/app dev      # http://localhost:3100
pnpm --filter @vylo/app build    # статический сайт в apps/vylo/out/
```

На десктопе приложение показывается в рамке iPhone с описанием продукта, на телефоне — на весь экран. Его можно
добавить на экран «Домой» (есть `manifest.webmanifest`).

`out/` можно выложить на любой статический хостинг (Vercel, Netlify, Cloudflare Pages, GitHub Pages, nginx).

## Что внутри

| Экран | Что умеет |
|---|---|
| Онбординг | Имя, интересы, стиль поездок, страны, где уже были → стартовый паспорт и XP. Ссылка, по которой пришёл человек, открывается сразу после онбординга |
| Карта | 3D-глобус MapLibre (спутник / схема), фото-пины мест, фильтры (места, еда, отели, природа, встречи), карусель ближайших мест, поиск, геолокация, подсветка посещённых стран, тап по стране → визы |
| Обзор | Сторис путешественников, «Место дня» с таймером, задания дня, популярные направления, гиды под интересы, встречи, отзывы, люди |
| Направление / место | Герой-фото с параллаксом, вкладки (обзор, места, виза, советы, встречи), факты, галерея, отзывы, «В поездку», маршрут в Google Maps |
| Встречи | Список, детали, участники, живой чат (организатор и участники отвечают), создание своей встречи |
| Визы | 38 стран для паспорта РФ: режим, срок, стоимость, документы-чек-лист, заметки |
| Сохранённое | Коллекции с обложками-мозаиками, поездки, все места |
| Поездка | Таймер до вылета, маршрут по дням, бюджет, визовый статус, чек-лист со стартовыми пунктами из визовых требований |
| Профиль | Уровень и XP, серия дней, задания, 13 достижений, отзывы, редактирование профиля |
| Паспорт | % открытого мира, штампы стран, отметка любой страны мира |
| Уведомления | Лента активности, которая обновляется каждый день |

### Почему в него хочется возвращаться

- **Серия дней** 🔥 — бонус XP растёт до 7 дней подряд, неделя на экране профиля, напоминание в уведомлениях.
- **Задания дня** — 3 новых задания каждый день в 00:00, награда забирается кнопкой.
- **Уровни и достижения** — 8 уровней от «Новичка» до «Легенды», 13 медалей с конфетти при открытии.
- **Место дня** — одно направление в сутки для всех, с обратным отсчётом до следующего.
- **Паспорт** — процент открытого мира и штампы стран; каждая новая страна — XP.
- **Социальные петли** — встречи с чатом, подписки, лайки отзывов и гидов, «поделиться» на каждой странице.

## Структура

```
src/
  app/                 маршруты (статический экспорт; /d, /p, /guide, /u, /visa — через generateStaticParams)
  components/
    map/               глобус, карточки карусели, поиск
    screens/           экраны детальных страниц
    app-shell.tsx      рамка устройства, статус-бар, сплэш, глобальные шторки и награды
    celebrations.tsx   модалки достижений / уровней / серии, тосты «+XP»
    global-sheets.tsx  «Создать», коллекции, поездки, отзывы, страна, сторис
  data/                направления, места, встречи, гиды, отзывы, визы
  lib/                 геймификация, уведомления, страны, утилиты
  store/               zustand: состояние пользователя (persist) и UI
```

## Заметки

- Фото — с CDN Unsplash. Если картинка не загрузилась, вместо неё рисуется аккуратная иллюстрация, а у аватаров —
  инициалы, поэтому интерфейс не ломается без сети.
- Спутниковые тайлы — Esri World Imagery (с атрибуцией). Под ними векторные границы стран из `world-atlas`, так что
  глобус работает и без тайлов. Источник можно заменить через `NEXT_PUBLIC_SATELLITE_TILES`.
- Визовая информация справочная — в приложении есть напоминание сверяться с консульством.
- Воркер MapLibre копируется в `public/` скриптом `scripts/copy-map-worker.mjs` при `dev` и `build`.
