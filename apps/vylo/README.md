# Vylo — карта путешествий

**Исследуй. Сохраняй. Встречайся. Делись.** Мобильное веб-приложение (PWA) для путешественников: 3D-глобус с
местами, визы для граждан РФ, встречи с путешественниками рядом, планировщик поездок и паспорт, который хочется
заполнять. Интерфейс и весь контент — на 6 языках.

Next.js 16 · React 19 · Tailwind v4 · Framer Motion · MapLibre GL (глобус) · Zustand. Полностью статический билд:
данные встроены, состояние пользователя хранится в `localStorage`, сервер не нужен.

## Запуск

```bash
pnpm install
pnpm --filter @vylo/app dev         # http://localhost:3100
pnpm --filter @vylo/app build       # статический сайт в apps/vylo/out/
pnpm --filter @vylo/app typecheck
pnpm --filter @vylo/app i18n:check  # проверка переводов (также в CI)
```

На десктопе приложение показывается в рамке iPhone с описанием продукта, на телефоне — на весь экран. Его можно
добавить на экран «Домой» (`manifest.webmanifest`). `out/` выкладывается на любой статический хостинг.

## Языки

Русский (эталон), English, Español, Deutsch, Français, Italiano. Язык определяется по браузеру и меняется в
онбординге, в настройках и в панели рядом с телефоном.

- `src/i18n/messages/*.ts` — словари интерфейса. Тип `Messages = Shape<typeof ru>` не даёт собрать проект, если в
  каком-то языке не хватает ключа или есть лишний.
- `src/content/*.ts` — тексты каталога (направления, места, гиды, встречи, отзывы). Записи типизированы по id, так что
  пропущенное место — ошибка компиляции.
- Множественное число — через `Intl.PluralRules` (ru: one/few/many/other, fr/es/it: one/many/other…); числа, деньги,
  даты, «5 минут назад», названия стран, языков и валют — через `Intl`.
- `scripts/check-i18n.mts` дополнительно проверяет плейсхолдеры `{name}`, все плюральные формы языка, пустые строки,
  кириллицу вне русского и строки, оставленные без перевода.

## Что внутри

| Экран | Что умеет |
|---|---|
| Онбординг | Язык, имя, интересы, стиль поездок, страны, где уже были → стартовый паспорт и мили |
| Карта | 3D-глобус (спутник / схема), фото-пины, фильтры, карусель ближайших мест, поиск на всех языках, посещённые страны, тап по стране → визы |
| Обзор | Сторис, «Место дня», маршрут дня, направления по России и миру, гиды, встречи, отзывы, люди |
| Направление / место | Оформление в цветах города (палитра + орнамент: волны, тории, купола, горы, северное сияние…), вкладки, факты, галерея, отзывы, «В поездку», маршрут |
| Встречи | Список, детали, участники, чат, своя встреча (закрытая — в Plus) |
| Визы | 43 страны для паспорта РФ: режим, срок, стоимость, документы, заметки |
| Поездка | Таймер до вылета, маршрут по дням, автомаршрут (Plus), бюджет, виза, чек-лист |
| Профиль | Статус и мили, «дни в пути», маршрут дня, 13 нашивок, редактор аватара, приглашение друга |
| Паспорт | % открытого мира, штампы, обложки паспорта (Plus) |
| Итоги | Километры, страны, части света, стиль путешествий; картинка для сторис (Plus) |

**Каталог:** 35 направлений (в т. ч. Байкал, Камчатка, Алтай, Петербург, Сочи, Териберка, Дагестан) и ~100 мест с
реальными фотографиями Unsplash.

### Почему в него хочется возвращаться

- **Мили и статусы** — 8 статусов, как у карты лояльности: от «Пассажира» до «Легенды дорог».
- **Дни в пути** — компас, а не огонёк; с Plus путь не прерывается при пропуске до 2 дней в месяц.
- **Маршрут дня** — 3 шага каждый день, одинаковые для всех.
- **Нашивки** — вышитые шевроны за реальные действия; при получении — посадочный талон.
- **Место дня**, паспорт со штампами, встречи с чатом, подписки и «поделиться» на каждой странице.

## Каталог мира

`src/data/world/countries/<код>.ts` — по файлу на страну: города, достопримечательности, **инстаместа** (где
получаются лучшие кадры), **скрытые места**, еда, «как добраться» из России, советы, путеводитель из 4 глав, визовые
правила и оформление — всё сразу на 6 языках. `pnpm --filter @vylo/app world` проверяет пакеты (координаты не дальше
150 км от города, у каждого города ≥ 4 мест, есть инстаместо и скрытое место, все тексты на всех языках, ID фото
Unsplash) и раскладывает их на факты (в бандле) и тексты (грузятся только для выбранного языка).

## Визы для любого паспорта

- Путешественник выбирает свой паспорт (любой из 199), при желании второй — для двойного гражданства — и отмечает
  визы и ВНЖ, которые у него уже есть (США, Великобритания, Шенген, Канада, Япония, ВНЖ ЕС, грин-карта, страны
  Залива…). Приложение показывает режим въезда в каждую из 98 стран, срок, стоимость и документы.
- Источники, от общего к частному: матрица Passport Index (`src/data/visa/matrix.ts`, обновляется
  `scripts/import-visa-matrix.mts`) → визовый гид страны (`src/data/visa/guides/<code>.ts`, поправки `overrides`) →
  подробные данные для паспорта РФ (`src/data/visa.ts`) → правки в админке («Визы по паспортам» на странице страны).
- Гид страны: как въехать и оформить визу, официальные порталы, онлайн-формы (TDAC, MDAC, K-ETA, ESTA…), продление,
  визараны с пунктами перехода, транзит без визы, визы для удалёнщиков, лайфхаки, частые ошибки, заметки для
  конкретных паспортов и исключения для владельцев других виз (Мексика, Грузия, Албания, Сербия, ОАЭ, Перу…).
- Калькулятор 90/180 (`/visa/calc/`) для Шенгена и других зон со скользящим окном.
- `scripts/build-visa.mts` проверяет гиды (все 6 языков, официальные https-ссылки, координаты, коды паспортов) и
  раскладывает их на факты и лениво загружаемые тексты по языкам; `scripts/visa-column.mts TH` показывает столбец
  матрицы для страны.

## Карта и маршруты

Глобус → улицы при приближении (схема: OpenStreetMap/CARTO; спутник: Esri с подписями и дорогами), все места точками
на GPU и фото-пины для видимой области, фильтры (города, места, инстаместа, скрытые, еда, природа, отели, встречи),
компас, 3D-наклон, масштабная линейка. Маршрут из любых мест: пешком / велосипед / авто, оптимизация порядка, время и
расстояние по отрезкам, пошаговые подсказки, передача в Apple Карты и Google Карты; без сети — оценка по прямой.

## Админ-панель

`/admin/` — панель в стиле macOS: обзор и состояние контента, места/города/страны (поиск, фильтры, редакторы с картой,
перетаскиванием метки, поиском адреса, загрузкой фото, текстами на 6 языках, ценой, часами, тегами, визой и
путеводителем), редактор карты (перетаскивание меток, новое место кликом), проверка фото, покрытие переводами,
модерация (отзывы, встречи, объявление, место дня, закреплённые направления), команда и роли (владелец, администратор,
редактор, модератор; приглашения, сброс пароля, передача прав владельца), журнал с отменой, экспорт/импорт.
С сервером [`apps/vylo-api`](../vylo-api/README.md) правки сразу видят все пользователи; без него — локальный режим.

## Vylo Plus

Всё главное бесплатно навсегда (глобус, места, визы, встречи, паспорт, геймификация). Plus — для тех, кто хочет
большего: автомаршрут, офлайн-режим, эксклюзивные гиды, итоги путешествий, режим отпуска, закрытые встречи, обложки
паспорта и аксессуары аватара, знак Plus. Цены: 299 ₽/мес или 1 990 ₽/год (−45 %), в Европе 4,99 €/29,99 €;
7 дней бесплатно. В демо подписка включается без оплаты.

## Фото

`src/lib/photos.ts`: если задан `NEXT_PUBLIC_UNSPLASH_ACCESS_KEY`, фото и имена авторов берутся через Unsplash API
(так требует [API Guidelines](https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines) для продакшена).
Без ключа используются прямые ссылки Unsplash. Если фото не загрузилось, рисуется иллюстрация в цветах города.
