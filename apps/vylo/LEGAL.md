# Vylo — права, лицензии и риски

Справка для владельца проекта. Это не юридическая консультация: перед коммерческим запуском покажите её юристу по IP.

## 1. Код

Весь код приложения написан для этого проекта с нуля: экраны, стили, анимации, иллюстрации (аватары, нашивки, компас,
орнаменты городов, обложки паспорта) нарисованы кодом (SVG/CSS), чужих шаблонов, UI-китов и ассетов нет.

Сторонние библиотеки — только с разрешительными лицензиями, допускающими коммерческое закрытое использование:

| Пакет | Лицензия |
|---|---|
| Next.js, React, Framer Motion, Zustand, Tailwind CSS, sonner, clsx, tailwind-merge, i18n-iso-countries | MIT |
| MapLibre GL JS | BSD-3-Clause |
| lucide-react, topojson-client | ISC |
| world-atlas (данные Natural Earth) | ISC / общественное достояние |
| Шрифт Inter (@fontsource-variable/inter) | SIL Open Font License 1.1 |

Требование этих лицензий — сохранять тексты лицензий в дистрибутиве (они лежат в `node_modules` и попадают в сборку
в виде комментариев). Экран «Лицензии и источники» перечисляет их пользователям.

## 2. Сходство с Duolingo

Игровые механики (серии, очки, уровни, задания) не охраняются авторским правом — охраняются конкретное оформление,
персонажи и товарные знаки. Чтобы не было даже визуальной ассоциации, в Vylo:

- нет совы/маскота, фирменного зелёного, огонька серии, «сердечек», «кристаллов» и лиг;
- вместо XP — **мили**, вместо уровней — **статусы как у карты лояльности** авиакомпании;
- вместо огонька — **компас** и «дни в пути», неделя нарисована как пунктирный маршрут;
- вместо шестиугольных медалей — **вышитые нашивки** (шевроны путешественника);
- вместо экрана «урок пройден» — **посадочный талон**;
- задания дня — «маршрут дня» в виде линии перелёта, конфетти — с бумажными самолётиками.

## 3. Название «Vylo»

Поиск по открытым базам нашёл знак **VYLO** (USPTO, заявка 98248873) в **классе 10** — медицинские изделия. Пересечения
с путешествиями (классы 9 — приложения, 39 — организация путешествий, 42 — SaaS, 43 — бронирование) не найдено.
До запуска: проверьте USPTO, EUIPO (TMview), WIPO Global Brand Database и Роспатент (ФИПС) по классам 9/39/42/43 и
подайте собственную заявку в нужных странах. Проверьте доступность домена и названий в App Store / Google Play.

## 4. Фотографии

- Источник — Unsplash, [Unsplash License](https://unsplash.com/license): бесплатно, в том числе коммерчески, без
  обязательной атрибуции. Нельзя: продавать фото без существенной переработки и собирать из них конкурирующий фотосервис.
- Используются только бесплатные фото, **не Unsplash+**.
- Для продакшена: подключите Unsplash API (`NEXT_PUBLIC_UNSPLASH_ACCESS_KEY`) — по правилам API нужно грузить фото
  с их CDN (hotlinking) и показывать автора. Код уже это поддерживает.
- На фото узнаваемых людей и брендов (вывески, логотипы) может требоваться отдельное разрешение для рекламы —
  в рекламных материалах используйте пейзажи и архитектуру.

## 5. Карта

- Границы стран — Natural Earth (общественное достояние).
- Спутниковые тайлы — **Esri World Imagery**: бесплатный доступ без ключа предназначен для некоммерческого и
  тестового использования. Для коммерческого запуска нужен аккаунт ArcGIS Location Platform (или замена на MapTiler,
  Mapbox и т. п.) — источник меняется через `NEXT_PUBLIC_SATELLITE_TILES`.
- Спорные территории: на глобусе только границы Natural Earth без подписей статуса; для отдельных рынков может
  потребоваться локальная версия карты.

## 6. Контент

- Описания мест, гиды и советы написаны для проекта (не скопированы с сайтов и путеводителей).
- Демо-профили, отзывы и встречи — вымышленные и помечены бейджем «Пример»; аватары сгенерированы, фото реальных
  людей не используются. Перед запуском замените демо-контент реальным или уберите его.
- Визовые данные — справочные, с напоминанием сверяться с консульством. Это снижает риск претензий, но данные нужно
  регулярно обновлять.
