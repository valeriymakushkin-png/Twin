# Vylo — органайзер поездок с автодневником

> **Статус: Этап 1 готов** (ядро). Дальше: Этап 2 (расходы), Этап 3 (карта и дневник).

## Что это и какую гипотезу проверяем
Приложение для путешественников. Главная гипотеза первой версии: людям нравится **автоматически собранный
красивый дневник поездки**, и они **делятся им в соцсетях**. Всё остальное (поездки, маршрут, документы,
расходы, карта) нужно, чтобы дневнику было из чего собираться.

## Жёсткие ограничения (не нарушать)
- **Никакого ИИ/LLM** в приложении. «Умное» — только алгоритмы, шаблоны и правила.
- **Никакого бэкенда, аккаунтов, серверов.** Всё на устройстве (local-first).
- **Полностью офлайн.** После первой загрузки приложение работает без сети; сеть нужна максимум для необязательного
  кэша курсов валют (Этап 2).
- **Данные и документы остаются на устройстве** и никуда не отправляются. Нет аналитики и трекеров внутри приложения.
- **Минимум платного и минимум зависимостей.** Каждую новую зависимость обосновывать (размер, лицензия, нужна ли).
- **Не добавлять функции вне списка без вопроса.** Особенно: друзья, соревнования, аккаунты, импорт из почты, ИИ,
  уведомления, общие поездки.

## Принятые решения
- PWA на React + TypeScript + Vite (не Expo): бесплатно, один код для телефона и веба, ссылка вместо магазина.
- Приложение живёт в `apps/trips`; существующее приложение `apps/vylo` (Next.js) не затрагивается.
- Интерфейс только на русском; все тексты в `src/core/strings.ts` (добавить язык — повторить объект).
- Города и координаты офлайн: встроенный список городов (GeoNames, CC BY 4.0, нужна подпись) — на Этапе 3.
- Карта на Этапе 3: офлайн-мир (границы стран из `world-atlas`, без тайлов) + пины; детальные карты улиц (PMTiles) —
  отдельным решением позже.
- Резервная копия: один файл `.vylo` (zip), необязательно шифруется паролем; **восстановление заменяет все данные**.
- В дневнике (Этап 3) пользователь может заменить любое фото своим: из галереи/камеры, с кадрированием, с кнопкой
  «Вернуть оригинал»; замена попадает в PDF и картинки.
- Как измерять гипотезу «делятся»: ссылка в подписи «Сделано в Vylo» на отдельную страницу с бесплатным счётчиком без
  cookie — **не в приложении**, решить перед запуском.

## Стек
React 19, TypeScript, Vite 8, **Dexie** (IndexedDB), **react-router** (HashRouter — не требует настройки сервера),
**dnd-kit** (перетаскивание), **vite-plugin-pwa** (офлайн, service worker), **fflate** (zip для копии),
**Web Crypto** (AES-GCM + PBKDF2 для PIN и пароля копии), шрифт Inter локально, **Vitest** + **fake-indexeddb**.
Будут: MapLibre GL + world-atlas (карта), jsPDF (PDF), Canvas (картинки для соцсетей).

    modules/

## Команды (из корня репозитория)
```
pnpm install
pnpm --filter @vylo/trips dev        # разработка: http://localhost:5173 (обновляется на лету)
pnpm --filter @vylo/trips build      # проверка типов + сборка в apps/trips/dist
pnpm --filter @vylo/trips preview    # сборка как у пользователя: http://localhost:4173 (тут работает офлайн-режим)
pnpm --filter @vylo/trips test       # тесты
pnpm --filter @vylo/trips typecheck
```
Важно: шифрование документов и service worker работают только на **https** или **localhost**. По обычному
`http://192.168…` с телефона PIN/документы и офлайн недоступны — для проверки на телефоне нужен https-хостинг
(Cloudflare Pages, Netlify, GitHub Pages — бесплатно) или тоннель.

## Данные и модель
- Даты — строки `ГГГГ-ММ-ДД` в местной зоне. Порядок записей в дне задаёт `order`, время — подпись; запись со
  временем сама встаёт по времени, перетаскивание меняет только порядок.
- Документы: в базе только шифртекст (имя/тип и содержимое отдельно). Ключ документов (DEK) обёрнут ключом из PIN;
  смена PIN перешифровывает только DEK. PIN ≥ 6 символов. Забытый PIN не восстановить (есть «сброс»: удаляет документы).
- Любое изменение схемы базы — новая `db.version(n)` в `core/db.ts`, чтобы не потерять данные пользователей.
- Версия формата копии — `BACKUP_VERSION` в `core/backup.ts`; более новый файл старое приложение отвергает.

## План этапов
1. **Ядро** — ГОТОВО.
2. **Простые расходы** — ввод за 2–3 касания, итоги по дням/категориям, бюджет с остатком, ручные курсы + необязательный
   кэш из бесплатного API, CSV. Тесты расчётов обязательны.
3. **Карта и дневник** (главное) — карта посещённых стран/мест, счётчики, дневник в 3+ стилях без ИИ, правка текста и
   порядка, замена фото, экспорт PDF и картинок (stories 9:16, квадрат 1:1) с подписью «Сделано в Vylo», итоговая
   карточка «N стран, N городов, N км». Тесты генератора дневника обязательны.

## Правила работы
- Этапами; после каждого — коммит в git с понятным сообщением и отчёт: что готово, как запустить, что проверить
  вручную, что дальше.
- Код понятный, с короткими комментариями; модули независимы.
- Развилка или неясность — вопрос, а не догадка. Владелец — новичок: объяснять простыми словами.
- Русские фразы дневника: город только в именительном падеже (склонять названия нельзя), числительные — через
  `plural()` из `core/strings.ts`.

## Известные ограничения Этапа 1
- Резервная копия собирается в памяти: очень большие объёмы фото/документов (сотни МБ) могут быть тяжёлыми для слабых
  телефонов.
- Браузер может очистить данные при нехватке места (особенно на iPhone). Приложение просит «постоянное хранилище»
  при добавлении документа, но гарантий нет — поэтому нужны копии.
- Короткий PIN слабо защищает от того, у кого есть сами файлы базы: рекомендуем длиннее 6 символов с буквами.
- Перетаскивание — за значок-«ручку» справа; между днями работает, во время перетаскивания страница автоматически
  прокручивается.
