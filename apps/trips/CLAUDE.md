# Vylo Дневник — органайзер поездок с автодневником

> **Статус: ЧЕРНОВИК (Шаг 0).** Стек и структура предложены, но ещё не подтверждены владельцем. Кода нет.
> После «ок» этот файл обновляется и дальше правится в конце каждого этапа.

## Что это и какую гипотезу проверяем
Приложение для путешественников. Главная гипотеза первой версии: людям нравится **автоматически собранный
красивый дневник поездки**, и они **делятся им в соцсетях**. Всё остальное (поездки, маршрут, документы,
расходы, карта) нужно, чтобы дневнику было из чего собираться.

## Жёсткие ограничения (не нарушать)
- **Никакого ИИ/LLM** в приложении. «Умное» — только алгоритмы, шаблоны и правила.
- **Никакого бэкенда, аккаунтов, серверов.** Всё на устройстве (local-first).
- **Полностью офлайн.** После первой загрузки приложение работает без сети; сеть нужна максимум для необязательного
  кэша курсов валют.
- **Данные и документы остаются на устройстве** и никуда не отправляются. Нет аналитики и трекеров внутри приложения.
- **Минимум платного и минимум зависимостей.** Каждую новую зависимость обосновывать (размер, лицензия, нужна ли).
- **Не добавлять функции вне списка без вопроса.** Особенно: друзья, соревнования, аккаунты, импорт из почты, ИИ,
  уведомления, общие поездки.

## Стек (предложение)
PWA: **React + TypeScript + Vite**. Локальная база **Dexie** (IndexedDB). Офлайн — **vite-plugin-pwa** (service worker).
Карта — **MapLibre GL** (границы стран из `world-atlas`, без тайлов; детальные PMTiles — позже, отдельным решением).
Перетаскивание — **dnd-kit**. Резервная копия — **fflate** (zip). PDF — **jsPDF**. Картинки для соцсетей — Canvas.
Шифрование PIN — **Web Crypto** (AES-GCM + PBKDF2). Тесты — **Vitest**. Шрифты — локально через `@fontsource`.

## Структура
```
apps/trips/
  CLAUDE.md
  package.json            (@vylo/trips: dev, build, preview, test, typecheck)
  index.html, vite.config.ts
  src/
    core/        db (Dexie), theme, online-status, backup, crypto (PIN), i18n, ui-kit
    modules/
      trips/       поездки: список, создание, обложка
      itinerary/   маршрут по дням, места/события, перетаскивание, фото к местам
      documents/   документы и фото, PIN, просмотр офлайн
      expenses/    траты, валюты, бюджет, итоги, CSV
      map/         карта стран и мест, счётчики (страны, города, км)
      diary/       генератор дневника, стили, редактор, экспорт PDF/картинки
    data/        списки стран и городов (офлайн)
  tests/         (или рядом с модулями: *.test.ts)
```

## Команды (появятся после Этапа 1)
```
pnpm install                      # из корня репозитория
pnpm --filter @vylo/trips dev     # запуск для разработки: http://localhost:5173
pnpm --filter @vylo/trips build   # сборка
pnpm --filter @vylo/trips preview # проверить сборку и офлайн-режим
pnpm --filter @vylo/trips test    # тесты (расходы, генератор дневника)
pnpm --filter @vylo/trips typecheck
```

## План этапов
1. **Ядро** — поездки, маршрут по дням, офлайн-база и индикатор сети, документы с PIN, резервная копия, темы.
2. **Простые расходы** — ввод за 2–3 касания, итоги, бюджет, ручные курсы + необязательный кэш, CSV.
3. **Карта и дневник** (главное) — карта посещённых стран и мест, счётчики, дневник в 3+ стилях без ИИ,
   правка текста и порядка, замена фото пользователем, экспорт PDF и картинок (stories 9:16, квадрат 1:1) с подписью
   «Сделано в Vylo», итоговая карточка «N стран, N городов, N км».

## Правила работы
- Двигаться этапами; после каждого — коммит в git с понятным сообщением.
- После каждого этапа отчёт: что готово, как запустить, что проверить вручную, что дальше.
- Код понятный, с короткими комментариями; модули независимы (`trips`, `itinerary`, `documents`, `expenses`,
  `diary`, `map`).
- Тесты: расчёт расходов и генератор дневника — обязательны.
- Развилка или неясность — задать вопрос, а не гадать.
- Новичок-владелец: объяснять решения простыми словами.
